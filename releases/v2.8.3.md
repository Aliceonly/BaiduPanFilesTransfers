# BaiduPanFilesTransfers v2.8.3

## 修复与改进

- 修复批量转存中的 `IndexError`、空值解析异常和原始输入行错位。
- 网络异常和临时转存错误自动重试，最多尝试 5 次；单条失败不再中断整批任务。
- 指定目录按有效链接分配编号，标题和不支持的格式不占用编号，也不会误用其他行的标题。
- 指定目录遇到同名文件冲突时选择另一个空目录，避免覆盖已有文件。
- 移除每条任务后的固定等待，并减少冗余目录请求。

## 下载与使用

- `BaiduPanFilesTransfers.exe`：Windows x64 单文件程序，无需安装 Python。
- `BaiduPanFilesTransfers-windows-x64.zip`：包含程序、许可、说明及构建信息，解压后运行。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。
- `BUILD_INFO.txt`：对应源码 Commit、Python 版本和实际构建依赖。

在 GitHub Actions Windows runner 上使用 Python 3.12 和 PyInstaller 构建，发布前执行 API mock 回归测试、源码 GUI 检查及打包后的主窗口启动检查。未使用真实 Cookie 执行网盘转存；不保证 Windows 7 或其他 architecture 兼容性。

请将程序放在可写目录中运行。首次使用需要输入自己的 Cookie；压缩包不包含个人 `config.ini`。程序未进行 Windows code signing。

源码和完整打包说明见本 Tag 的 `docs/BUILD_WINDOWS.md`。本项目遵循 GPL-3.0，保留原作者署名与许可。
