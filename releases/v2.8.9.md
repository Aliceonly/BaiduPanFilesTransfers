# BaiduPanFilesTransfers v2.8.9

## 重置当前批次

- 在总进度旁增加「重置进度」按钮，清空链接输入框、当前进度和内存断点，恢复「批量分享」「批量转存」按钮。
- 运行中或暂停时先取消任务，等待当前请求结束后完成重置；旧批次的后台结果不会更新新批次的界面。
- 保留 Cookie、保存目录、选项和现有日志；已经完成的网盘操作不会撤销。

## 批量转存优化

- 带提取码和无提取码的链接均支持后台预读；每批次最多 2 个读线程，排队及已完成但未消费的预读结果合计最多 4 条。
- 每个读线程复用独立 Session，每条链接隔离提取码认证，减少混合链接批次中的无效预读和重复连接。
- 指定目录模式的存在性和非空检查使用短路探测；普通模式仍保留完整、及时的目录快照，用于核对结果未知的转存。
- 目录分配、转存写入和断点推进仍按输入顺序串行执行，保留取消、恢复和结果核对保护。
- 增加分阶段 HTTP 请求计数、累计耗时和重试等待日志，以及完全离线的基准脚本。

性能统计是截至日志输出时已结束请求的快照，并行请求累计耗时不能相加作为总耗时。离线模拟测试不代表真实百度网盘速度，本版不承诺固定吞吐或官方安全 QPS。

## 下载与使用

- `BaiduPanFilesTransfers.exe`：Windows x64 单文件程序，无需安装 Python。
- `BaiduPanFilesTransfers-windows-x64.zip`：包含程序、许可、说明及构建信息。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。
- `BUILD_INFO.txt`：对应源码 Commit、Python 版本和实际构建依赖。

Release workflow 会在 Windows runner 上执行 API mock regression tests、源码 GUI 检查和打包后的 EXE 主窗口启动检查，通过后才发布。测试不访问真实百度网盘，实际账号与链接仍需自行验证。

断点仅保存在当前程序进程的内存中，关闭窗口或重启后无法恢复。目标平台为 Windows 10/11 x64，不保证 Windows 7 或其他 architecture 兼容性；程序未进行 Windows code signing。请在可写目录中运行，不要上传或分发包含个人 Cookie 的 `config.ini`。
