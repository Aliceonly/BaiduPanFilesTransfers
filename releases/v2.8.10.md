# BaiduPanFilesTransfers v2.8.10

## 批量分享重试与继续

- 修复分享接口返回错误码 `2` 时直接放弃的问题：按临时错误自动重试，每轮最多请求 5 次，每次重试等待 1～2 秒。
- 首轮结束后，对仍未成功的已知临时失败条目最多再补试 2 轮；成功条目不会重复创建分享，同一条目的各次请求沿用最初的提取码。
- 分享进度只统计成功条目。仍有未成功条目时显示「分享未完成」，按钮改为「继续分享」，保留成功链接和原有分享设置，只继续处理未成功条目。
- Cookie 失效等确定性错误，以及结果未知的条目，保留待处理，不自动追加补试轮次。排除限制后可点击「继续分享」；要放弃当前批次，点击「重置进度」。
- 待继续分享时禁用批量转存，避免覆盖当前批次。分享断点仅保存在当前进程内存中，关闭程序后会丢失。

## 界面默认设置

- 批量分享默认勾选随机生成提取码；取消勾选后可输入统一提取码。
- 「指定目录」默认勾选，仅对批量转存生效，批量分享不受影响。
- 移除「使用帮助」入口，原位置显示总进度；Cookie 输入错误时直接提示重新复制完整 Cookie。

## 下载与验证

- `BaiduPanFilesTransfers.exe`：Windows x64 单文件程序，无需安装 Python。
- `BaiduPanFilesTransfers-windows-x64.zip`：包含程序、许可、说明及构建信息。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。
- `BUILD_INFO.txt`：对应源码 Commit、Python 版本和实际构建依赖。

Release workflow 在 Windows runner 上执行 API mock 回归测试、源码 GUI 检查及打包后的 EXE 主窗口启动检查，通过后才发布。100 条分享的离线回归覆盖其中 2 条先失败后恢复的场景，验证最终 100/100 成功、其余 98 条不重复请求、提取码保持不变；这不代表真实百度网盘账号或永久性错误一定能够成功。
