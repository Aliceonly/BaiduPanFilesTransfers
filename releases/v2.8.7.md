# BaiduPanFilesTransfers v2.8.7

## 目录编号与转存恢复修复

- 为每项任务保留稳定的目录编号，支持从紧邻的编号标题继承目录；同名冲突使用 `7_2`、`7_3` 等后缀，不占用下一项的 `8`，避免后续标题与目录整体错位。
- 指定目录创建后重新检查内容，只有确认为空才转存；每项最多尝试 3 个不同转存目录，次数跨 resume 保留。
- unknown 转存结果保留原目录、source snapshot 和 checkpoint；恢复时分享内容变化或原先已知 metadata 缺失，不会发送新内容的转存请求或清除旧断点。
- 目录 API 逐条校验身份信息，损坏页整页 bounded retry，不返回部分列表。不可信 baseline 或损坏的核对列表不能作为自动确认成功的证据。
- 检测模式不读取或创建目标目录，也不执行转存。

## 链接解析与请求安全

- 修复 `51、3D game` 等标题编号、`51.[archive]/sub` 等显式目录，以及 `7.https://...` 紧贴 URL 的编号解析。
- URL scheme 的大小写不再影响显式目录；URL 本身不会被拼入目录名。
- 提取码优先使用 URL 的 `pwd`，其次为明确标签和紧随链接的 code；支持无空格标签及括号格式，不把解压密码或普通说明误当成提取码。
- 只处理首个 URL 为可信百度网盘 origin 的输入；分享页逐跳检查 redirect，拒绝外站跳转和 HTTP 降级。
- 全部网络请求启用 TLS certificate verification，并移除全局警告屏蔽。证书错误不会自动关闭校验；使用 HTTPS 代理时需要正确配置代理证书和受信任证书链。

## 下载与使用

- `BaiduPanFilesTransfers.exe`：Windows x64 单文件程序，无需安装 Python。
- `BaiduPanFilesTransfers-windows-x64.zip`：包含程序、许可、说明及构建信息。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。
- `BUILD_INFO.txt`：对应源码 Commit、Python 版本和实际构建依赖。

Release workflow 会在 Windows runner 上执行 API mock regression tests、源码 GUI 检查和打包后的 EXE 主窗口启动检查，通过后才发布。测试不访问真实百度网盘，实际账号与链接仍需自行验证。

断点仅保存在当前程序进程的内存中；关闭窗口或重启后无法恢复。目录内容的递归核对尚未实现，证据不足的 unknown 转存会保留 checkpoint。

目标平台为 Windows 10/11 x64，不保证 Windows 7 或其他 architecture 兼容性；程序未进行 Windows code signing。请在可写目录中运行，不要上传或分发包含个人 Cookie 的 `config.ini`。
